# byemi - block all xiaomi connections!

to set up:
1. open AdAway
2. press the button to update sources, in the main menu
3. press the red **+** button that is located at the bottom right
4. make sure list format is set to **block** and type is set to **URL**
5. set the **location** as this link: `https://github.com/raincandee/byemi/blob/main/blocklist.txt`
6. press the update hosts warning that (should) appear
7. you're all done! your phone is now no longer connecting to xiaomi services, telemetry, etc.
