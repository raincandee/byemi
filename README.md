# xiaomi-subdomain-blocklist

A blocklist for [AdAway](https://github.com/AdAway/AdAway) that blocks all known subdomains owned by Xiaomi.

## Installation

1. Open **AdAway**.
2. Go to the **Hosts sources** menu (the screen that shows whether your hosts sources are up to date).
3. Press the **+** button in the bottom-right corner.
4. Set **List format** to `Block`.
5. Set **Type** to `File`.
6. Choose any label you want.
7. Select the `blocklist.txt` file.

That's it! Update your hosts sources to apply the blocklist.
This will effectively make it impossible for your phone to connect to any Xiaomi service!
